GitOps turns a Git branch into a running F5 Distributed Cloud HTTP load balancer. Each environment forwards requests to `https://httpbin.org` and owns a separate namespace, origin pool, load balancer, and Terraform state.

The [custom xcsh Terraform provider](https://github.com/f5-sales-demo/terraform-provider-xcsh) translates Terraform resources into F5 Distributed Cloud API calls. This demo pins its signed release `15.5.2` and commits the provider lock file.

Start with [Set up the demo](./setup/), then [Deploy a branch](./deploy/) and [Verify a deployment](./verify/). [Architecture](./architecture/) explains state and concurrency. [Clean up a branch](./cleanup/) and [Troubleshoot deployments](./troubleshooting/) cover operation and recovery. [Terraform reference](./terraform/) maps the configuration to provider resources.
